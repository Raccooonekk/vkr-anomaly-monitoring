# Приложение доступа к результатам мониторинга

Директория содержит Streamlit-приложение оператора системы предиктивного мониторинга аномалий производительности.

## Запуск на Kaggle

```bash
streamlit run app/monitoring_dashboard.py --server.port 8501 --server.address 0.0.0.0
```

Приложение читает результаты из директории:

```text
/kaggle/working/vkr_anomaly_monitoring_outputs
```

## Основные разделы

- обзор экспериментального запуска;
- метрики регрессионных и классификационных моделей;
- панель мониторинга состояния обработанных наборов данных;
- контроль целостности manifest.

Приложение не изменяет исходный датасет и не выполняет запись в `/kaggle/input`.
