# Веб-панель предиктивного мониторинга

Директория содержит Streamlit-приложение для демонстрации разработанной системы предиктивного мониторинга аномалий производительности микросервисной архитектуры.

Панель предназначена для подготовки скриншотов к главе 3 ВКР и для просмотра результатов Kaggle-пайплайна:

- обзор текущей и прогнозируемой `p95_latency`;
- сравнение фактической и предсказанной задержки на тестовой выборке;
- сравнение регрессионных моделей с baseline;
- визуализация RPC-карты микросервисов по сценариям `compose`, `home`, `user`;
- ранжирование сервисов по риску деградации;
- журнал риск-событий и контроль нештатных ситуаций.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run dashboard/streamlit_app.py
```

## Запуск в Kaggle

Приложение читает результаты из каталога:

```text
/kaggle/working/vkr_anomaly_monitoring_outputs
```

При необходимости можно указать другой путь через переменную окружения:

```bash
export VKR_OUTPUT_ROOT=/kaggle/working/vkr_anomaly_monitoring_outputs
streamlit run dashboard/streamlit_app.py
```

## Режим демонстрационных данных

Если реальные файлы `reports/regression`, `predictions/regression` и `predictive_processed_dataset` отсутствуют, панель автоматически переходит в демонстрационный режим. Это позволяет подготовить скриншоты интерфейса до запуска полного Kaggle-пайплайна. После появления реальных результатов приложение автоматически использует их вместо демонстрационных данных.

## Метаданные микросервисов

В каталоге `dashboard/metadata` размещены небольшие справочные файлы:

- `rpc_map.csv` — RPC-взаимодействия для сценариев `compose`, `home`, `user`;
- `service_placement.csv` — размещение микросервисов по узлам.

Эти файлы не содержат исходный датасет и используются только для построения визуализаций архитектуры вызовов.
